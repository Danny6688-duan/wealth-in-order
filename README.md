# 财富有序 v1.1.0 使用说明

统一入口：https://danny6688-duan.github.io/wealth-in-order/

手机、电脑和平板均打开这个网址，使用之前已授权的同一个 GitHub 账户登录。电脑上的“打开财富有序”启动文件也会打开该网址。无需让 Mac 保持开机。

## 这次新增了什么

- **账户流水**：把收入、支出和内部转账关联到具体现金或存款账户，支持分类、备注和筛选。
- **CSV 导入**：选择账户、映射列、预览校验后整批保存；相同记录跳过，冲突和错误阻止整批写入。
- **余额对账**：用期初余额和流水计算账面应有金额，与实际余额比较，保存核对依据及差额。
- **统一版本管理**：所有日常入口使用同一套页面与业务规则，页脚显示应用版本。有新发布时提示刷新；有未保存输入时先提醒保留。

原有资产管理、预算、固定收支、定投、资产追踪、分配与策略、决策工作台继续保留。应用版本表示软件发布，“账本修订”随保存数据增加。

## 第一次使用账户流水

1. 打开“资产与持仓”，将现金或存款拆分为真实账户。新增明细时同步减少或删除对应汇总，避免重复计算资产。流水账户不能关联尚未拆分的汇总资产。
2. 进入“账户流水”，点击“关联现有账户”，选择已有资产，填写期初日期、该日开始前的余额和依据。关联账户不会再增加一份总资产。
3. 点击“＋ 记录流水”，填写日期、收入或支出、发生账户、金额，按需填写分类和备注。金额用正数，日期不能晚于今天，也不能早于账户期初日期。
4. 内部转账选择“转账”，填写转出及转入账户。双方必须是不同的已关联账户，只记录转出方一笔，不将另一方再登记为收入。转账不计入生活消费。

原有收支记录会继续参与统计，不会自动变成账户流水。已经在“收支与预算”登记的同一笔收入或消费，不要再次录入或导入。

## 怎样导入 CSV

点击“导入 CSV”，选择导入账户，填写固定的账单来源名称，选择文件和编码，再核对列映射。

必须映射日期、类型、金额；可以映射分类、备注、外部流水ID和转入账户。文件以逗号分隔，支持 UTF-8、GB18030/GBK；先移除账单开头的说明行，保留表头和流水。日期采用 YYYY-MM-DD，类型填收入、支出、转账，或 income、expense、transfer。金额不带货币符号，最多两位小数；单次最多2000行、文件不超过2MB，解码后的 UTF-8 内容也不能超过2MB。

先点击“预览并校验”，检查可导入、重复和错误数量。预览不保存数据；全部错误解决后，才可点击“确认导入”。文件或映射改变后需要重新预览。

同一账户、来源和外部流水ID的相同记录会跳过，内容不一致则报冲突。没有ID时按完整内容去重。两笔真实交易即便日期、金额和备注完全相同，也应填写不同的稳定流水ID；重复导入时保持账单来源名称一致。

## 怎样核对余额

在账户卡片点击“核对实际余额”，填写今天从银行等渠道核实的余额、依据和差额说明，再点击“确认实际余额”。系统会更新关联资产的余额和日期，重新计算当前规划，保留本次对账结果，不改写旧快照，也不虚构一笔收入或支出来补平差额。

例如：期初1000元，收入200元，支出30元，转出100元，账面应有1070元。实际只有1060元时显示差额−10元，应核实是否遗漏流水。余额日期早于新流水时，页面会分别显示余额日应有金额和截至今天的账面金额。

## 多设备与备份

多设备共用同一份账本。若另一台设备已保存，旧页面不能直接覆盖新数据；先保留未保存输入，再点击“同步最新”并重新核对。定期在“规划与备份”导出完整 JSON，新流水及对账记录也包含在内。

电脑上原有 SQLite 账本和升级前副本保留作恢复用途，不会自动覆盖现有在线账本。需要恢复备份时，先确认恢复来源和当前备份已妥善保存。

目前账户流水按人民币处理。银行、支付宝、微信和券商账单没有自动同步；投资买卖、负债还款与自动交易尚未接入账户流水，也未接入 MCP。账单列映射不等于已适配所有平台的原始导出格式。
